# トラップオブリリー（TRAP OF LILY）

古い館の娘リリィは剣を持てず、夜ごとやって来る侵入者から逃げ回ることしかできません。プレイヤーは館の罠を仕掛けて、リリィを守ります。刻命館のように「主人公は逃げ回るだけ、戦うのは罠」というブラウザゲームです。

## 遊び方

- 日本語と英語で遊べる（端末の言語で始まり、タイトルの言語ボタンか「設定」で切り替え）。設定では音楽と効果音の音量も変えられ、クレジットも見られる。
- モードは3つ。**ステージ**（全40。1ステージ＝1夜で、クリアすると次が開く。5ステージごとに部屋が変わり、部屋は大広間・回廊・温室・東の書庫・地下牢・礼拝堂・屋根裏・大時計の間の8つ。クリアの評価は星3つ）、**チャレンジ**（全10夜を続けて守り、ハイスコアを競う）、**エディット**（床・壁・奈落・トゲ床・シャンデリア・槍の石像・扉・開始位置を置いて自分の部屋を作り、強さ1〜10で試せる）。記録・実績・自作の部屋はこの端末に保存される。
- スマホを縦に持って始めると、盤面が縦長（横10×縦15）になる。横持ち・PCは横長のまま。
- 始める前の「支度」で、逃げる子を4人（リリィ・ミーナ・ノエル・セシル）から1人、罠を11種類から4つ選びます。逃げる子はそれぞれ能力が違い、得意な罠を1つ持ちます（リリィ＝送り返しの陣、ミーナ＝火柱、ノエル＝氷床、セシル＝落石）。得意な罠を持っていくと、その罠がとても強くなります（罠ボタンの★）。
- 逃げる子の移動は CPU まかせです。かしこさが上がるほど上手に逃げ、侵入者を罠の上へ誘うようになります。慌てると混乱して走り回ることもあります。
- プレイヤーは選んだ罠をマスに置くだけです。同じ罠をもう一度押すと撤去できます（払った魔力の半分が戻る）。
- 罠: トラバサミ（足止め）、跳ね床（吹き飛ばし）、落石（遅れて大ダメージ）、火柱（十字）、氷床（進んでいた向きへ壁まで滑らせる）、送り返しの陣（入ってきた扉へ戻す）、振り子刃（直線4マス）、誘いの鈴（侵入者を鈴へ向かわせる）、まきびし（弱いが侵入者の足もとに直接置ける）、つむじ風の陣（周りの侵入者を吸い寄せる）、火薬樽（踏まれて1秒後に周り3x3が爆発。先を読んで置く）。
- 置いた罠の上に別の罠を置くと**合成**になり、2つの罠が1マスで続けて作動する（少し強くなり、罠の数は1つのまま。火柱＋落石＝溶岩落とし など名前付きの組み合わせもある）。
- 侵入者には罠との**相性**がある（騎士は火柱に弱く振り子刃・まきびしに強い、盗賊はまきびし・トラバサミ・火薬樽に弱く落石に強い、重装兵は火柱・火薬樽に弱く落石・振り子刃・まきびしに強い）。弱点に当てると「効いた！」。
- 夜のあいだ床に**宝物**（金貨・宝石・王冠）が出る。逃げる子が拾うと得点、罠で取ると2倍。
- **実績**は20種類（連続・合成・ステージ・自作の部屋のクリアなど）。
- チャレンジは5夜ごとに部屋が変わる（第1〜5夜は大広間、第6〜10夜は東の書庫）。ゲーム内の「遊び方」で、罠と館の仕掛けの使い方を図で見られる。
- 魔力は時間で溜まります。罠を3秒半以内に続けて当てると「連続」になり、得点と魂が増えます。罠に当たった侵入者はよろけて動きます（火柱・まきびしは1歩前、落石は1歩後ろ、トラバサミは抜け出したあと1歩前、振り子刃は刃の向き、槍の石像は外へ）。動いた先に罠を置いておくと連鎖します。1回で2体以上に当てると「ダブルヒット」、飛ばした侵入者を他の侵入者にぶつけると「玉突き」で、得点が大きく増えます。倒した侵入者は約1.5秒その場に倒れたまま残り（動かない）、罠を当てると「追い打ち」で連続が続きます。
- 館にはもともと仕掛けがあります。トゲ床、奈落（跳ね床で落とすと一撃）、シャンデリアと槍の石像（押すと発動、魔力不要）。
- 夜は「準備」のあとフェイズ1〜3と進み、フェイズごとに置ける罠が増えます。夜明けまで守るか、侵入者を全滅させればクリアです。
- チャレンジでは、夜を越えるたびに集めた魂で館と逃げる子を強くできます（ステージはステージが進むほど館の備えが少しずつ強くなります）。

操作: PC は 1〜4 で罠を選んでマスをクリック、置くときのドラッグか Q / E で矢印のある罠の向き、Enter で準備を終える、P で一時停止。スマホは罠を選んでマスをタップ（矢印のある罠は向けたい方向へフリック）。

## 構成

| パス | 内容 |
|---|---|
| `src/game.html` | ゲーム本体（HTML 1 枚。外部スクリプト・外部フォントなし。オフラインで動く） |
| `tools/build.py` | `src/game.html` から `index.html`（GitHub Pages 用）と `dist-artifact/trap-maiden.html`（claude.ai Artifact 用）を作る |
| `docs/art-brief.html` | ChatGPT に頼むグラフィックと演出の提案 |
| `art-src/` | ChatGPT に描いてもらった原画（4人の設定画 `<名前>_sheet.webp`、参考の絵は `reference/`） |
| `tools/import_sprites.py` | ChatGPT に作ってもらった 48px のスプライトシート（`art-src/sprites48/`）のずれを直して `art/sprites/` に入れる（4人と侵入者3種の歩行、4人の被弾。ピンチの絵は服が破れる表現なので使わない） |
| `tools/import_fx.py` | エフェクトの絵（`art-src/fx/`、8 コマ横長か 3x3）を、マゼンタのふちを消して `art/fx/`（384x48）に入れる |
| `tools/cut_happy.py` | 喜びの立ち絵（`art-src/happy/`、白背景）の背景を抜いて `art/portrait_<名前>_happy.webp` にする（全10夜クリアの結果画面で使う） |
| `tools/import_icons.py` | 罠のアイコン（`art-src/icons/icon_*.png`、金枠つき）のマゼンタを消し、64x64 にそろえて `art/icons/` に入れる（罠ボタン・支度画面・確認画面で使う） |
| `tools/import_bgm.py` | BGM（`art-src/bgm/` の mp3）を音量 -18 LUFS・モノラル 64kbps にそろえて `art/bgm/` に入れる（ffmpeg を使う）。場面ごとの曲はタイトル・準備・第1〜5夜・書庫（第6〜9夜）・フェイズ3・最後の夜・ショップ、ジングルは夜明けと終わり |
| `docs/sound-fx-brief.html` | BGM・エフェクト・効果音の提案（Gemini 用プロンプト） |
| `tools/make_fonts.py` | フォント（Shippori Mincho B1・Zen Maru Gothic、SIL OFL）を `src/game.html` に出てくる文字だけに絞って `art/fonts/*.woff2` にする。文言を増やしたら動かし直す（`pip install fonttools brotli`）。ライセンス文は `art/fonts/OFL-*.txt` |
| `src/lang/en.js` | 英語の訳。ゲームの文言は日本語のまま `$t\`…\`` で書き（`${}` は訳では `{0}` `{1}` …）、ページの HTML は起動時に訳す。端末の言語（ストア版は Steam の言語）で決まり、タイトルの言語ボタンか設定で切り替え |
| `tools/i18n_check.py` | 訳の抜けを表示する（`--add` で訳のない文言を `null` で足す）。字句の読み取りは `tools/i18n_lib.py` |
| `desktop/` | Windows 版（Electron）。`npm install` → `npm run dist` で `desktop/dist/win-unpacked/`（Steam に上げる中身）と zip を作る。セーブは `%APPDATA%\TrapOfLily\save.json` にも書く（Steam クラウド用）。`steam.json` に App ID を入れると Steam の実績・言語・オーバーレイを使う |
| `steam/` | Steam で出すための文章・画像・手順（`steam/README.md`）。画像は `tools/make_capsules.py`・`tools/make_ach_icons.py`・`tools/sim/shot_store.js` で作る |
| `tools/make_sprites.py` | 手で組み立てたドット絵の予備（`art/sprites_gen/`） |
| `tools/cut_sheet.py` | 設定画から3方向を切り出して背景を抜き、`art/*.webp`（盤面用と立ち絵）を作る。ビルドで HTML に埋め込む |
| `tools/sim/` | ヘッドレスブラウザでの動作確認（罠を活かす AI の比較、地形と仕掛けの確認） |

## 更新の流れ

1. `src/game.html` を直す
2. `python tools/build.py`
3. 動作確認（下記）
4. コミットして push（GitHub Pages に反映される）。Artifact は `dist-artifact/trap-maiden.html` を publish する

## 動作確認

```bash
python -m http.server 8766 --bind 127.0.0.1
```

別のターミナルで（`playwright-core` と Chrome が必要。`PLAYWRIGHT_CORE` に playwright-core の場所を指定してもよい）:

```bash
node tools/sim/sim_terrain.js
node tools/sim/sim_lure.js
node tools/sim/sim_fullrun.js     # 全10夜を通しで遊んだときの時間と終わり方
node tools/sim/sim_balance.js 30  # 逃げる子4人×罠の組み合わせを自動ボットで比べる（1組30回）
node tools/sim/shot_select.js     # 支度の画面とプレイ画面のスクリーンショット（tools/sim/out/）
node tools/sim/shot_mobile.js     # スマホの縦・横でプレイ画面が1画面に収まるか
node tools/sim/shot_map2.js       # 第6夜で東の書庫に移るか
node tools/sim/shot_help.js       # 遊び方の全ページ
node tools/sim/test_flick.js      # スマホのフリックで矢印のある罠の向きを決められるか
node tools/sim/rec_walk.js lily   # 盤面で歩く様子を連続で撮る（止まったときにマスの中心にいるかも確認）
node tools/sim/test_fx_sound.js   # 効果音をすべて鳴らし、絵のエフェクトが出るか
node tools/sim/test_english.js    # 英語で全画面を開き、日本語の残り・文字のはみ出しを調べる（index を付けると index.html で）
python tools/i18n_check.py         # 訳の抜け
(cd desktop && node prepare.js && node test/test_desktop.js)  # ストア版のセーブ・復元・言語・終了（Linux は Xvfb が要る）
```

127.0.0.1 で開いたときだけ、デバッグ用に `window.__wanakan.G` でゲーム状態を読めます。
